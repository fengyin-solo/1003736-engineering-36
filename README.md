# 水文监测站网管理系统

面向水文监测站点运行、水位流量雨量数据采集、遥测设备维护与数据整编发布的水文站网管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 部署前初始化（bootstrap）

应用挂载前会执行 `frontend/src/data/bootstrap.ts` 的本地数据初始化：

- **幂等**：初始化状态（结构版本 + 各步骤检查点）记录在 `localStorage` 的
  `hydrology-monitor-station:init`，同一结构版本只完整生效一次，重复启动直接跳过。
- **旧数据兼容**：旧结构（占位符、缺字段）的仪器检定记录会按新结构迁移补录——仪器编号补录为
  `INST-` 序列、检定单位/检定结论按状态补齐、有效期按检定周期推算；待送检记录的有效期保留留空，
  不虚构日期。
- **巡检联动**：检定数据就绪后，巡检模块同步生成核查项（临期、已到期、不合格、缺有效期各一条，
  编号 `INSP-<仪器编号>` 确定，不会重复生成）。
- **失败回退与断点重试**：每个步骤先快照再执行，任一步骤失败会把该步骤写出的内容整批回退，
  并记录失败步骤；下次启动从失败的步骤继续，已提交的步骤不重跑。

构建前会自动跑一遍初始化自检（`prebuild`），也可手动执行：

```bash
cd frontend
npm run check:bootstrap   # 四个场景：全新初始化 / 重复初始化 / 旧数据迁移 / 失败回退+断点重试
```

仪器检定页提供三个联动面板：**临期视图**（已到期或 30 天内到期）、**送检待办**（待送检 +
到期需复检）、**检定验收**（送检中记录确认合格/标记不合格），清空浏览器数据刷新后即可用
示例数据完整重放。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydrology-monitor-station:entries` 这一项，或调用 `resetModule(模块)`。
